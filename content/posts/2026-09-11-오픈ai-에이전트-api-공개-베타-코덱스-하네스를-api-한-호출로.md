## 오픈AI가 에이전트 실행 환경을 API로 열었다

오픈AI가 9월 10일 **에이전트 API(Agents API)**를 공개 베타로 출시했다.  
자체 코딩 에이전트 '코덱스(Codex)'를 돌리던 하네스(harness·실행 프레임워크)를 API 한 호출로 쓸 수 있게 한 것이다.  
세션 생성·오케스트레이션·컨텍스트 압축·복구를 오픈AI가 맡고, 개발자는 도구와 실행 환경만 지정하면 된다.

## 관리형 하네스가 한 번에 처리하는 것들

자료에 따르면 관리형 하네스는 다음 네 가지를 기본 지원한다.

- 샌드박스(격리된 실행 공간)에서 코드 실행·파일 편집
- MCP 서버 연결로 외부 도구 호출
- 아티팩트(작업 산출물) 자동 생산
- 서브에이전트 최대 4개 동시 실행(멀티에이전트 설정)

웹 검색·프로그래머틱 툴 호출·MCP 전송도 기본 도구로 들어간다.  
모델은 예시 코드에 `gpt-6-astra`가 쓰였으나 정식 모델명은 아직 공개되지 않았습니다.

## 환경 선택이 비용·보안·레이턴시를 가른다

에이전트 API는 실행 환경을 세 가지 중 하나로 고른다. 샌드박스 없이도 실행 가능하다.

- **오픈AI 호스팅**: 샌드박스 프로비저닝(자원 할당·준비)·관리까지 자동
- **셀프 호스팅**: 워크스페이스 디렉터리(작업 폴더)·스킬 디렉터리(재사용 스크립트 모음)를 직접 지정
- **파트너 샌드박스**: 제3자 샌드박스 서비스 연동

이 선택이 비용·보안·레이턴시에 직결된다.

## 요금·지역·데이터 정책이 한국 도입을 막는다

청구 구조는 세 갈래로 나뉜다.

- 모델 사용량 → 선택한 모델의 API 요율
- 오픈AI 툴(웹 검색 등) → 표준 요율
- 오픈AI 호스팅 샌드박스 → 컨테이너 요율

**데이터는 미국 리전에만 남으며 제로 데이터 리텐션(ZDR·즉시 삭제)은 지원하지 않는다.**  
무료 티어·한국 리전·원화 결제 여부는 자료에 없다.  
국내 기업이 바로 도입하려면 법무·컴플라이언스 검토가 선행돼야 한다. 이 대목이 걸린다.

## 커뮤니티는 '단순 VM 래퍼가 아니다'라고 본다

해커뉴스 댓글 78개 중 다수는 **하네스가 VM 바깥에서 돌며 필요할 때만 VM과 통신**한다는 점을 짚었다.  
에이전트 실행을 VM 단위로 스케일링하지 않아도 된다는 뜻이다.  
반면 "클로드 코드보다 낫지 않다" "오픈코드보다는 낫다"는 비교도 나왔다.  
자체 관리형 에이전트를 이미 운영 중인 팀은 "따라 할 만하다"는 반응도 보였다.

## 쉽게 풀어보면

오픈AI가 **코덱스라는 코딩 비서를 뒤에서 돌리던 엔진을 API로 풀어놨습니다.**  
뷔페에서 음식을 직접 담던 걸, **메뉴만 말하면 주방에서 알아서 요리해 가져다주는 셰프**를 고용한 셈입니다.  
개발자는 "이 저장소 읽고, 저 서버 붙이고, 테스트 돌려" 같은 지시만 내리면 됩니다.  
샌드박스·서브에이전트·MCP도 한 번에 붙습니다.  
다만 **주방이 미국에만 있고, 재료(데이터)도 미국에 남으며, 가격표는 아직 달러로만 나옵니다.**  
한국 개발자가 오늘 바로 쓰려면 미국 리전 요금을 감수하고, 데이터 보관 규정을 통과해야 합니다.

## 나에게 미치는 영향

**일반 사용자·학생·직장인은 오늘 당장 쓸 수 없습니다.**  
API 키·SDK 설정·서버 인프라가 필요한 개발자 대상 서비스입니다.  
파이썬·자바스크립트·고(Go) 중 하나를 다룰 줄 안다면, 오픈AI 사이트에서 API 키를 발급받아 퀵스타트를 돌려볼 수는 있습니다.  
**무료 크레딧은 없으니 소액 결제 테스트부터 시작하세요.**  
기존에 클로드 코드·커서·윈드서프 같은 유료 코딩 에이전트를 쓴다면, 에이전트 API가 그 도구를 대체할지 여부는 **직접 벤치마크해 봐야 알 수 있습니다.**  
국내 클라우드·보안 정책상 미국 리전 데이터 보관이 걸린다면, 셀프 호스팅 옵션으로 사내 서버에서 돌리는 쪽을 검토하세요.

## 남은 건 검증된 벤치마크와 한국 리전

오픈AI가 공개한 성능 수치는 **벤더 제공 자료일 뿐 독립 벤치마크가 아닙니다.**  
실제 프로덕션 워크로드에서 레이턴시·비용·안정성이 어느 수준인지는 커뮤니티 실측이 쌓여야 알 수 있습니다.  
한국 리전·원화 정산·ZDR 지원 일정은 아직 공개되지 않았습니다.  
본지가 앞서 다룬 클로드 주간 사용량 인상 기사 때처럼, **공식 발표 수치와 실사용자 체감 사이에 틈이 있는지 지켜볼 필요가 있습니다.**
