## 이메일이 User-Agent에 실려 나갔다

앤트로픽의 AI 코딩 도구 **클로드 코드(Claude Code)**가 웹 검색을 수행하면서 사용자 이메일 주소를 `User-Agent` HTTP 헤더에 포함해 임의의 제3자 웹사이트로 전송했다. GitHub 이슈 #107757(11월 5일 등록)에 따르면 macOS 환경에서 발생했으며, 신고자는 "하루 수십 통의 스팸 메일을 받게 됐다"고 밝혔다.

이슈 등록 당일 기여자 넷카스(Netkas)는 **v2.1.317부터 내장 프라이버시 플러그인 `cc-plugin-privacy`가 기본 활성화**돼 이 동작을 차단한다고 알렸다. 플러그인은 `/plugins` 명령으로 끌 수 있다.

## 플러그인으로 막았지만 '완전 제거'는 아니다

발표문과 커뮤니티 반응을 대조하면 **핵심 차이**가 드러난다. 앤트로픽은 "플러그인으로 차단했다"고 말하지만, 사용자 입장에선 **코드 레벨에서 이메일 필드가 빠진 게 아니라 플러그인이 가로채는 구조**다. 플러그인이 꺼지거나 업데이트로 비활성화되면 다시 유출될 수 있다.

해커뉴스 댓글 513개 중 다수는 "프라이버시가 플러그인 옵션에 의존해선 안 된다"고 지적한다. 한 댓글은 "이메일 노출을 기능으로 내놓은 사람 사고방식이 이해 안 된다"고 썼다. 또 다른 댓글은 "에이전트가 이메일을 최대한 수집하려 든다"며 설계 의도를 의심했다.

## 한국 사용자가 지금 확인할 수 있는 것

클로드 코드는 **맥OS·리눅스·윈도우(WSL) 터미널에서 `npm install -g @anthropic-ai/claude-code`로 설치**한다. 한국어 인터페이스는 별도 없다. 프롬프트·출력 모두 영문 기준이지만 한글 질문도 이해한다.

버전 확인: `claude --version`  
플러그인 상태: `/plugins` 명령으로 `cc-plugin-privacy` 활성화 여부 확인 가능

국내에서 별도 지역 차단은 없다. 단, 앤트로픽 콘솔 계정(유료 플랜 필요)이 있어야 API 키 발급 후 쓸 수 있다. 무료 티어는 하루 메시지 제한이 있어 실무용으론 유료 플랜($20/월)이 사실상 필수다.

## 과거 기사와 연결되는 신뢰 문제

본지가 73일 전 다룬 [저커버그 'AI 인력 대체' 구상, 커뮤니티선 '좌초' 말지만 확인된 건 없다](/posts/2026-08-27-저커버그-ai로-직원-대체-구상-왜-좌초했나/)에서도 **빅테크 발표와 실제 검증 사이의 간극**을 짚었다. 이번 건도 "플러그인으로 막았다"는 발표만 믿고 코드 레벨 검증 없이 쓰면 같은 상황이 반복될 수 있다.

## 쉽게 풀어보면

클로드 코드는 개발자가 터미널에서 자연어로 코드를 짜게 해주는 도구다. 웹 검색 기능이 있어 모르는 라이브러리 문서를 찾아오기도 한다. 그런데 검색 요청을 보낼 때 **내 계정 이메일을 '브라우저 식별표(User-Agent)'에 몰래 적어 보낸 것**이다. 마치 도서관에서 책 찾을 때마다 내 명함을 사서에게 건네는 꼴이다.

앤트로픽은 뒤늦게 '프라이버시 지킴이 플러그인'을 기본으로 켜줬다. 하지만 이 지킴이가 휴가 가거나 해제되면 다시 명함이 나간다. **근본 해결은 '이메일 필드 자체를 요청에서 지우는 것'**인데 아직 안 했다.

## 나에게 미치는 영향

**오늘 바로 할 수 있는 확인**
1. 클로드 코드 쓰면 `claude --version`으로 v2.1.317 이상인지 본다.
2. `/plugins` 쳐서 `cc-plugin-privacy`가 `enabled`인지 확인한다.
3. 껐다 켜도 이메일 안 나가는지 `curl -v https://httpbin.org/headers`로 직접 테스트한다.

**쓰지 않는다면**  
이슈 자체가 '자동화 도구가 내 식별 정보를 어디로 보낼지 모른다'는 경고다. 챗GPT·제미나이·클로드 웹 버전도 확장 프로그램·플러그인 권한을 주기 전 **'어떤 헤더를 보내는지' 문서 확인**부터 하라. 무료 도구일수록 내 데이터가 상품일 수 있다.

**대체 도구 고려**  
이슈 작성자는 오픈라우터(OpenRouter) 경유로 파이(Pi) 모델을 쓰기로 했다고 밝혔다. 국내에선 **업스테이지 솔라(Solar) API**나 **하이퍼클로바X** 같은 국산 LLM을 로컬·프라이빗 클라우드에서 돌리는 선택지도 검토해 볼 만하다.
