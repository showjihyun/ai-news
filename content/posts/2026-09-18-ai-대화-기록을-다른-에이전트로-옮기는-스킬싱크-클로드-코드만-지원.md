## 클로드 코드에서만 작동하는 세션 이동 도구

해커뉴스에 올라온 YC W26 배치 **스킬싱크(SkillSync)**는 AI 채팅 세션을 다른 에이전트로 옮기는 도구입니다. **현재 클로드 코드(Claude Code) 환경에서만 작동합니다.**

커뮤니티 댓글에 따르면 JSONL 형식의 대화 기록을 마크다운으로 변환한 뒤, 전체 도구 입출력까지 포함해 클로드 코드가 청크 단위로 읽어들이는 방식입니다. 세션을 직접 이어받는 '핸드오프' 용도로는 작동합니다. 다만 마크다운을 읽는 과정에서 컨텍스트 오버헤드가 발생한다고 개발자가 인정했습니다.

## 오픈소스 핵심, 커뮤니티가 먼저 만들려 했다

핵심 코드가 오픈소스로 공개됐습니다. 한 댓글 작성자는 "네가 안 만들었으면 내가 만들었을 것"이라며 환영했습니다. 별도 작성자는 같은 이름으로 '스킬싱크'(스킬 공유)와 '컨텍스트싱크'(맥락 공유) 두 도구를 이미 만들어 썼다고 밝혔습니다. 한 모델로 설계하고, 다른 모델로 반복 검토하고, 다시 다른 모델로 구현하는 워크플로에 쓰고 있다고 설명했습니다.

**이 대목이 걸립니다.** 발표문엔 없는 제약이 너무 많습니다. 파이썬 실행 환경 필수. 한국어 인터페이스 없음. 설치 프로그램도 없습니다.

## 한국에서 바로 쓸 수 있을까

클로드 코드는 앤스로픽이 제공하는 개발자용 터미널 에이전트입니다. 한국에서도 앤스로픽 콘솔 계정이 있으면 설치해 쓸 수 있습니다. 스킬싱크는 파이썬 스크립트로 JSONL을 마크다운으로 변환하는 과정이 필요합니다. 따라서 **파이썬 실행 환경과 클로드 코드 CLI가 모두 갖춰진 머신에서만 바로 테스트 가능합니다.** 한국어 메뉴나 원클릭 설치기는 아직 없습니다.

## 기존 유료 도구 대체 가능성 낮음

대화 기록 이동만 해결해 줍니다. 코드 생성, 리뷰, 테스트 실행 같은 개발 전반을 커버하는 커서(Cursor)나 윈드서프(Windsurf) 같은 유료 IDE 에이전트를 대체하기엔 기능 범위가 좁습니다. 무료로 쓸 수 있는 오픈소스라는 점은 장점입니다. 단, 클로드 코드 유료 구독이 전제돼야 합니다. **구독 요금은 아직 공개되지 않았습니다.**

## 쉽게 풀어보면

**스킬싱크는 앤스로픽의 개발자 도구 '클로드 코드'에서 진행한 AI 대화 기록을 다른 AI 에이전트에게 넘겨주는 도구입니다. 지금은 클로드 코드에서만 작동합니다.**

비유하자면, 클로드 코드라는 직원이 작성한 업무 일지(JSONL)를 누구나 읽기 쉬운 마크다운 보고서로 바꿔서, 다음 직원(다른 AI 모델)에게 "여기까지 했으니 이어서 해줘"라고 건네주는 셈입니다. 다만 보고서가 길어지면 다음 직원이 읽는 데 시간이 걸리는 '컨텍스트 오버헤드'가 생깁니다.

핵심 코드는 오픈소스라 누구나 뜯어보고 고칠 수 있습니다. 이미 비슷한 도구를 직접 만들어 쓰던 개발자도 있었고, "좋은 시도"라고 격려하는 반응이 많았습니다.

한국 개발자가 오늘 바로 쓰려면: 파이썬이 깔린 터미널에서 클로드 코드 CLI를 띄우고, 스킬싱크 스크립트를 내려받아 실행하면 됩니다. 한국어 메뉴나 원클릭 설치기는 없습니다. 챗GPT나 제미나이 대화 기록을 옮기는 용도로는 아직 쓸 수 없습니다.

## 나에게 미치는 영향

**클로드 코드 구독자라면** 스킬싱크로 세션을 백업해 두었다가 다른 머신이나 다른 모델로 넘겨보세요. 공식 문서에 따라 JSONL 내보내기·불러오기를 테스트해 보면 됩니다.

**클로드 코드를 안 쓰는 일반 사용자라면** 챗GPT·제미나이·클로드 웹에서 대화 기록을 내보내기(Export) 기능으로 JSON 받으신 뒤, 직접 새 대화창에 붙여넣는 수밖에 없습니다. 자동 이동 도구는 아직 없습니다.

**개발 팀 리더라면** 오픈소스라 내부 보안 정책에 맞춰 포크(Fork)해 쓸 수 있습니다. 단, 마크다운 변환 단계에서 민감 코드가 평문으로 노출될 수 있으니 검토 후 도입하세요.

## 남은 쟁점

- 클로드 코드 외 에이전트 지원 일정은 아직 공개되지 않았습니다.
- 컨텍스트 오버헤드를 줄이기 위한 압축·요약 기능도 로드맵에 있는지 확인되지 않았습니다.
- 한국어 문서화와 패키지 매니저 등록(Homebrew, pip 등)도 향후 과제입니다.
