## 레딧이 RSS와 공개 API를 2027년 3월까지 없앤다

테크크런치 보도다. 레딧이 수요일 모더레이터·개발자 대상 업데이트에서 **RSS 피드 지원 중단**과 **공개 API 접근 종료**를 발표했다. 종료 시점은 둘 다 2027년 3월이다. 모더레이터용 RSS 대안인 '디스코드 릴레이 데빗' 앱으로의 이전 기한은 11월 13일까지다.

표면 이유는 "대규모 스크래핑과 자동화된 남용의 통로가 됐다"는 것. AI 봇이 레딧 데이터를 무단 수집해 학습에 쓴다는 주장이다.

## 매출 구조를 보면 속내가 보인다

레딧 2분기 실적을 보면 다른 그림이 나온다. 광고 외 수익(**'기타 수익'**)이 전년 대비 **24% 증가해 4,300만 달러**를 기록했다. 이 항목의 핵심은 **AI 기업과의 데이터 라이선스 계약**이다.

공개 API와 RSS로 데이터를 무료 제공하면, 돈 주고 사는 기업의 구매 유인이 떨어진다. 레딧 입장에서 데이터 수도꼭지를 잠그는 건 수익 보호 조치다. 해커뉴스 댓글에서도 "레딧이 사용자 콘텐츠를 AI 기업에 팔 독점권을 쥐려는 것"이란 지적이 나왔다. **데이터 장사를 위해 열린 웹 인프라를 걷어차는 모양새다.**

## 모더레이터와 연구자, 서드파티 앱이 직격탄

모더레이터들은 RSS로 스팸 감지·커뮤니티 알림을 자동화해 왔다. 레딧은 디스코드 릴레이 데빗 앱을 대안으로 제시했지만, 모더레이터 커뮤니티 밖에서 RSS를 쓰던 용도(연구, 아카이브, 개인 구독 등)는 대체재가 없다.

공개 API 종료로 타격받는 주체는 소셜 리스닝 상품 운영사, 학술 연구자, AI 어시스턴트 개발사, 승인받지 못한 서드파티 앱·봇 개발자다. 개발자 등록 마감은 2027년 1월 12일까지다.

올드 레딧(클래식 텍스트 버전)도 **최근 6개월 내 접속한 로그인 사용자만 접근 가능**하게 바뀐다. 당초 90일이었으나 발표 직전 6개월로 연장됐다.

## 쉽게 풀어보면

레딧은 인터넷 초창기부터 쓰이던 **RSS(구독 피드 표준 방식)**와 **공개 API(누구나 데이터 끌어다 쓰는 창구)**를 2027년 3월까지 없앱니다.

비유하자면 **도서관이 "책 훔쳐가는 사람이 많다"며 열람실 문을 잠그고, "우리 책 보려면 돈 내고 계약해라"**라고 통보한 셈입니다. 표면 이유는 'AI 봇이 데이터를 긁어간다'지만, 속사정은 **레딧 사용자가 쓴 글·댓글을 AI 학습용으로 팔아 돈을 벌고 있기 때문**입니다.

실제로 레딧은 올 2분기 광고 외 수익(주로 AI 데이터 판매)이 4,300만 달러로 24% 늘었습니다. 데이터를 공짜로 풀면 장사가 안 되니, 수도꼭지를 잠그는 겁니다.

이 결정으로 가장 타격받는 건 **자원봉사로 커뮤니티를 굴려온 모더레이터들**입니다. 스팸 걸러내고 알림 돌리던 자동화 도구(RSS 기반)가 11월 13일까지 작동 안 하면, 일일이 손으로 확인해야 합니다. 무보수 노동에 의존하던 플랫폼이 도구마저 빼앗는 건 비판받아 마땅합니다.

## 나에게 미치는 영향

**일반 레딧 사용자라면:** 레딧 앱·웹사이트만 쓰면 당장은 변화가 없습니다. 다만 올드 레딧(old.reddit.com)을 즐겨 썼다면, **최근 6개월 내 접속 기록이 없다면 접근이 차단**될 수 있습니다. 지금이라도 한 번 접속해 두세요.

**RSS 리더(피들리 등)로 레딧 구독 중이라면:** 2027년 3월까지만 작동합니다. 그 뒤로는 레딧 공식 앱·웹으로만 새 글을 볼 수 있습니다.

**서드파티 레딧 앱(아폴로, 릴레이 등) 사용자라면:** 앱 개발자가 2027년 1월 12일까지 레딧에 등록하지 않으면 API 접근이 끊겨 앱이 작동하지 않습니다. 쓰는 앱 개발자 공지를 확인하세요.

**AI 챗봇(챗GPT, 클로드 등)으로 레딧 내용 물어보던 분이라면:** 공개 API가 닫히면 챗봇이 레딧 최신 대화를 실시간으로 인용하기 어려워집니다. 레딧과 별도 계약한 서비스만 가능해집니다.

## 남은 쟁점

데이터 독점 확대가 가속화될 것으로 보입니다. 플랫폼이 사용자 생성 콘텐츠를 자산화해 AI 기업에 팔고, 열린 웹 인프라(RSS, 공개 API)를 차단하는 흐름입니다.

모더레이터 이탈 위험도 큽니다. 무보수 노동에 의존하던 레딧이 도구마저 빼앗으면, 커뮤니티 유지 동력이 떨어질 수 있습니다.

국내 레딧 유입 경로(디시인사이드·에펨코리아 등에서 레딧 링크 공유·RSS 구독)도 차단됩니다. 한국 사용자 커뮤니티가 대체 플랫폼으로 이동할지 지켜봐야 합니다.

레딧의 이번 조치는 **"열린 웹의 종언"**을 알리는 신호입니다. 플랫폼이 데이터 주권을 쥐고 수익화할 때, 사용자와 개발자·연구자가 잃는 건 접근권만이 아닙니다. 커뮤니티를 지탱하던 자율적 인프라입니다.
