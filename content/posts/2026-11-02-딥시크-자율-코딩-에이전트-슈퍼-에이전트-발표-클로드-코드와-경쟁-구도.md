## 발표만 있고 데모는 없다

중국 AI 스타트업 딥시크가 자율형 코딩 에이전트 '슈퍼 에이전트'를 발표했다. 앤스로픽의 개발자 도구 클로드 코드를 정조준한 행보다.

투자 매체는 'IPO 직전 견제'로, 기술 매체는 '기능 대결'로 기사를 썼다. 국내 매체는 번역 보도에 그쳤다. **어느 매체도 데모 링크나 실사용 후기를 싣지 않았다.**

원문 어디에도 한국어 지원, 국내 접속, 요금제, API 여부는 등장하지 않는다.

## 한국 개발자가 확인할 수 없는 것들

클로드 코드는 터미널에서 작동하는 AI 개발 도구다. 자연어로 지시하면 파일 읽기·작성·테스트를 수행한다. 슈퍼 에이전트도 자율 코딩을 내세운다.

발표 자료에 다음은 **공개되지 않았습니다**.

- 한국어 인터페이스 여부
- 국내 접속 가능 여부
- 요금제·무료 한도
- API 제공 여부와 가격
- 기존 IDE 연동 방식

데모 없이 '자율적'이라는 단어만으로 성능을 가늠하기는 어렵다. 한국 개발자가 오늘 확인할 수 있는 건 없다.

## 쉽게 풀어보면

**딥시크가 자율 코딩 도구 '슈퍼 에이전트'를 발표했다.** 이 도구는 개발자가 "로그인 페이지 만들어줘"라고 말하면 파일 생성부터 테스트까지 알아서 해주는 AI 비서다.

비유하자면 레시피만 주면 재료 손질·조리·플레이팅까지 끝내주는 주방 로봇이다. 경쟁 도구인 클로드 코드는 이미 나와 있다. 터미널(명령창)에서 작동하며 자연어 지시를 코드로 바꿔 실행해 준다.

**문제는 한국 개발자가 오늘 당장 슈퍼 에이전트를 써볼 수 있느냐다.** 발표문 어디에도 한국어 메뉴, 한국 결제, 한국 서버 이야기가 없다. 중국 서비스 특성상 본토 외 지역 접속 차단·실명 인증 요구 가능성을 배제할 수 없다. 접근성만 놓고 보면 이미 국내에서 쓸 수 있는 도구가 한 발 앞선다.

## 매체 보도, 정작 중요한 질문은 빠졌다

투자 매체 두 곳은 앤스로픽 IPO 시점을 거론했다. 기술 매체 두 곳은 벤치마크·기능 비교에 집중했다. 국내 매체는 번역 보도에 머물렀다.

**어느 쪽도 '한국 사용자 진입 장벽'을 묻지 않았다.** 발표문이 영문·중문만 있고 데모·가입 링크가 없는 탓도 있다.

서비스 리뷰 관점에서 보면 핵심 정보(요금·접속·언어)가 전부 빠진 채 '출시'만 알린 셈이다. 발표는 났는데, 한국 개발자가 만져볼 건 아직 없다.

## 나에게 미치는 영향

**지금 당장 할 수 있는 일: 딥시크 슈퍼 에이전트 공식 페이지·가입 링크·요금 안내 중 공개된 게 없다.**

대신 이미 쓰는 도구 점검은 해볼 만하다.

- 챗GPT·클로드·제미나이에서 코딩 답변이 이상하면 새 대화창에서 다시 물어보세요. 컨텍스트 초기화만으로 해결되는 경우가 많다.
- 깃허브 코파일럿, 커서 등 타 도구 무료 한도를 비교해 보세요.
- 회사·팀 단위라면 보안 정책(코드 외부 전송 여부)을 다시 확인하세요.

딥시크 쪽에서 한국어 베타 모집 공고가 뜨면 개발자 커뮤니티에 가장 먼저 올라올 것이다. 그때 가서 실제 코드 품질·응답 속도·한국어 주석 이해도를 직접 테스트해보고 갈아탈지 정해도 늦지 않는다. **기다리는 쪽이 이득이다.**

## 실물 검증 전까지는 판단을 보류한다

발표 시점만 보면 앤스로픽 IPO 흥행에 찬물을 끼얹으려는 의도로 읽힙니다. 하지만 **서비스 리뷰 관점에서 볼 때 지금 판단할 자료는 없다.**

요금제가 무료 티어 없이 엔터프라이즈 전용이면 개인 개발자는 배제됩니다. 한국어 자연어 이해도가 떨어지면 실무 투입은 불가능합니다. 보안 검증 없이 사내 코드베이스에 붙이기는 위험합니다. 지켜보자.
