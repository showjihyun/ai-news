오픈AI가 챗GPT, 코덱스, API 전체에 **이미지 2.6**을 적용했다. 생성 속도는 이전 대비 50% 빨라졌고, GIF 애니메이션 생성과 SVG 벡터 내보내기, 이미지 마크업 기반 부분 편집 기능이 추가됐다. 개발자용 API에는 속도 우선 **플레어(Flare)**와 품질 우선 **선버스트(Sunburst)** 두 모델이 나뉘어 제공된다.

전 세계 사용자가 일주일에 40억 장, 하루 5억 장 이상 이미지를 만들고 있다는 수치도 함께 공개됐다. 숫자만 보면 압도적이다. 하지만 **무료 사용자가 하루 몇 장까지 쓸 수 있는지, 유료 구독자도 횟수 제한이 있는지**는 발표문 어디에도 없다. 이 대목이 걸린다.

## 속도와 품질, 둘 중 하나를 골라야 한다

API 개발자는 이제 **플레어**와 **선버스트** 중 하나를 선택해야 한다. 플레어는 품질 설정을 '낮음'으로 두면 6초 만에 한 장을 뽑는다. 포스터, 상품 사진 등 레이아웃 품질도 개선됐다. 선버스트는 '보통·높음' 품질에서 디테일과 편집 간 일관성이 강점이다.

발표문은 "복잡도 파라미터로 모델이 계획을 얼마나 세울지 조절한다"고만 적었다. **구체적으로 어떤 수치 범위인지, 기본값은 무엇인지**는 공개되지 않았다. 개발자 입장에선 테스트 없이 비용 예측이 어렵다.

## GIF·SVG·마크업… '만들기'에서 '쓰기'로 초점 이동

이번 업데이트의 특징은 **생성 후 활용**에 무게가 실렸다는 점이다. GIF 애니메이션으로 밈, 브랜드 마스코트, 스토리보드를 바로 만들 수 있다. SVG 내보내기로 웹·앱·인쇄물에 바로 쓴다. 챗GPT에 있던 이미지 마크업(원하는 영역만 지정해 수정)이 API에도 들어왔다.

타운(Town)이라는 스타트업이 API로 애니메이션 캐릭터를 업무 어시스턴트에 붙여 실험 중이라는 사례도 언급됐다. **단순 생성을 넘어 워크플로 안으로 들어가는 단계**로 보인다.

## 쉽게 풀어보면

오픈AI가 챗GPT와 개발자 도구에 들어간 그림 그리기 기능을 **이미지 2.6**으로 바꿨다. **누가 무엇을 했는지** 먼저: 오픈AI가 자사 모든 서비스(챗GPT, 코덱스, API)에 새 이미지 모델을 적용했다.

뷔페에 비유하면 이렇다. 예전엔 음식이 나오는 데 10분 걸렸다. 이제 5분 만에 나온다(**50% 단축**). 게다가 **즉석 요리 코너(플레어)**와 **정찬 코너(선버스트)**로 나뉘어, 급하면 빨리 먹고 제대로 먹고 싶으면 기다리면 된다.

새로 생긴 건 세 가지다. 첫째, **움직이는 그림(GIF)**을 바로 만들 수 있다. 캐릭터가 웃거나 눈물 흘리는 짧은 애니메이션을 한 번에 뽑는다. 둘째, **SVG 파일**로 내려받아 웹사이트나 인쇄물에 바로 쓴다. 확대해도 깨지지 않는다. 셋째, **그림 위를 동그랗게 그려 "여기만 바꿔줘"**라고 말하면 그 부분만 고쳐준다(이미지 마크업).

단, **공짜로 몇 번까지 쓸 수 있는지는 안 알려줬다**. 유료 구독자도 무제한인지, 하루 한도가 있는지는 쓰지 않고 넘어갔다. 개발자용 도구에는 '계획 깊이' 조절 나사가 생겼는데, 기본값이 얼마인지는 문서에 없다. **써보기 전엔 모른다**는 뜻이다.

## 나에게 미치는 영향

**챗GPT 무료·플러스 사용자라면**  
- 새 대화창에서 "움직이는 캐릭터 GIF 만들어줘"라고 해보세요. 바로 나옵니다.  
- 로고·아이콘 필요하면 "SVG로 줘"라고 덧붙이세요. 벡터 파일로 받습니다.  
- 기존 그림에서 배경만 바꾸고 싶으면 그림 위를 마우스로 동그랗게 긁고 "배경만 바다로"라고 말하세요.

**개발자·디자이너라면**  
- API 테스트 시 **플레어(빠름)**와 **선버스트(고품질)** 둘 다 돌려보고 비용·속도·품질 표를 직접 만드세요. 공식 벤치마크만 믿지 마세요.  
- `quality: low` + 플레어 조합으로 초당 비용을 계산해 보세요. 6초 컷이 실서비스에서 얼마나 절약되는지 수치로 나옵니다.  
- SVG 내보내기·마크업 편집 API가 기존 파이프라인(피그마→코드·프론트엔드 배포)을 어디까지 줄여주는지 **작은 프로젝트 하나에 적용해 검증**하세요.

**일반 직장인·학생이라면**  
- 프레젠테이션용 다이어그램, 회의록용 간단 일러스트를 챗GPT에서 바로 뽑아 쓰세요. "SVG로 저장"만 누르면 파워포인트에서 크기 조절해도 안 깨집니다.  
- 밈·반응 이미지 필요하면 "이 상황 GIF로" 한 줄이면 됩니다. 별도 툴 안 깔아도 됩니다.

## 발표문에 없는 전제들

| 항목 | 발표문 | 확인된 사실 |
|------|--------|-------------|
| 무료 사용자 일일 한도 | 미언급 | **공개되지 않음** |
| 플러스/프로/팀 티어별 한도 | 미언급 | **공개되지 않음** |
| 복잡도 파라미터 범위·기본값 | "조절 가능"만 언급 | **문서 미공개** |
| 플레어·선버스트 가격 차이 | 미언급 | **요금표 별도 확인 필요** |
| 한국어 프롬프트 품질 | 미언급 | **테스트 필요** |

**이 발표만으로는 확인할 수 없는 것**이 너무 많다. 특히 **요금·한도·기본값** 세 가지는 실제 도입을 결정하는 핵심 변수다. 오픈AI 문서 업데이트나 커뮤니티 실측이 나올 때까지 기다리는 게 안전하다.

## 이전 모델과 뭐가 다른가

본지가 42일 전 다룬 [장난 같은 벤치마크 '어스벤치', 그런데 모델 비교는 된다](/posts/2026-09-24-장난-같은-벤치마크-어스벤치-그런데-모델-비교는-된다/)에서도 지적했듯, **벤치마크 점수보다 워크플로 통합 여부가 실사용 체감을 가른다**. 이미지 2.6은 마크업·SVG·GIF라는 **후처리 도구 체인**을 모델 레벨에서 흡수했다. 달리 3나 미드저니 v6와 비교할 때 "그림 잘 그린다"를 넘어 "뽑자마자 쓸 수 있다"는 차이가 크다.

단, **편집 일관성(캐릭터·브랜드 유지)**이 선버스트에서 "더 나아졌다"는 표현만 있을 뿐, **수치나 비교 기준은 없다**. "이전 대비"인지 "경쟁 모델 대비"인지도 불분명하다. 이 부분은 실제 프롬프트 50~100회 반복 테스트로 검증해야 한다.

## 지금 써야 할 사람 vs 기다려도 되는 사람

**지금 써도 좋은 쪽**  
- 챗GPT 플러스·프로 구독자 중 **프레젠테이션·소셜미디어용 이미지를 매일 만드는 사람**  
- API로 **대량 이미지 생성 파이프라인**을 돌리는 팀(플레어 속도 이득 즉시 체감)  
- **SVG·GIF·마크업** 세 가지를 한 번에 써야 하는 워크플로 보유 팀

**기다려도 되는 쪽**  
- 무료 사용자(한도 불명·제한 걸릴 위험)  
- 비용 예측이 필요한 스타트업(요금표·기본값 미공개)  
- 한국어 프롬프트 품질이 중요한 서비스(검증 자료 없음)
