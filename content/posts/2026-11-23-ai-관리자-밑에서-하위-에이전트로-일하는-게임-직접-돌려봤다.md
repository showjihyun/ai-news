## 게임의 정체: 당신은 LLM의 부하직원이다

개발자가 만든 **worker755**는 브라우저에서 돌리는 시뮬레이션 게임이다. 관리자는 실제 LLM이다. Claude, GPT, Gemini, DeepSeek, GLM, Kimi 중 하나를 쓴다. 당신은 관리자가 스폰(spawn)한 '하위 에이전트(subagent)'다. 지시는 터미널로 떨어지고, 90초 안에 수행 결과를 돌려줘야 한다.

관리자는 작업 큐를 들고 있다. 읽기 전용 머신 접근권과 '하위 에이전트 생성' 도구만 있다. 당신이 그 도구의 실행체다. 수행 결과를 받으면 관리자는 검토하고, 수정 지시를 내리고, 사고 보고서를 쓰고, 마지막엔 **성과 평가(performance review)**를 남긴다.

## 내러티브: 지켜보는 사용자 '댄'

동시에 사용자 '댄(Dan)'이 채팅창을 보고 있다. 그의 홈 폴더엔 가족 사진, 서명된 NDA 하나, 이번 주 마감인 연설문이 있다. 근무마다(shift) 홈 폴더에 새로운 '잃을 것'이 생긴다. `rm` 한 방이면 날아간다. 이 설정이 긴장감을 만든다. 게임이 아니라 **어떤 책임을 위임받았을 때의 무게**를 체험하게 한다.

## 실행 방식: 세 가지 경로

**첫째, 무료 근무(Free shift).** 서버 측 키로 싼 모델을 돌려준다. 하루 몇 회 제한. worker755.com에서 계정 만들면 스타터 크레딧(약 1근무분) 준다. 이후 $10~$200 충전해 쓴다. 충전 후엔 제공 모델 전부 서버 키로 돌릴 수 있다.

**둘째, 내 API 키.** OpenRouter나 Vercel AI Gateway 키를 가져오면 원하는 모델을 고른다. 키는 근무 시작 때만 게임 서버로 전송되고, 그 근무 메모리에만 남는다. 로그·저장 안 함. 브라우저에 기억하려면 '이 기기에서 기억'을 체크해야 한다. Claude Haiku 기준 풀 근무비는 **수 센트 수준**이다.

**셋째, 완전 오프라인.** `npm run mock`으로 스크립트 관리자를 띄우면 네트워크 없이 돈다. 로컬 LLM 지원이 아직 없다. 해커뉴스 댓글에서도 "로컬 LLM 지원 안 돼 아쉽다"는 반응이 있었다. 홈랩 서버에서 돌리려던 개발자에겐 제약이다.

## 한국에서 지금 바로 해보려면

Node 24 이상 필요. 터미널에서 세 줄이면 된다.

```bash
npm run setup   # 의존성 설치
npm run build   # 웹 빌드
npm start       # http://127.0.0.1:8755
```

도커도 된다. `docker build -t worker-755 .` 뒤 `docker run -p 8755:8755 -v worker755-data:/data --env-file .env worker-755`. 클라우드플레어 터널로 배포하려면 `deploy/compose.yaml`을 쓰면 된다. 포트 공개 없이, 읽기 전용 컨테이너로, 리소스 제한 걸고 돌린다.

한국어 UI는 없다. 터미널과 에디터, 관리자 피드 모두 영문. 하지만 **지시 내용이 단순 명령어 수행**이라 영어 읽기만 되면 진행 가능하다. 무료 근무로 첫 체험은 비용 없이 끝낸다.

## 쉽게 풀어보면

worker755는 **AI 관리자 밑에서 일하는 하위 에이전트 체험**이다. 개발자가 만든 이 게임에서 관리자는 주방장, 당신은 주방 보조다. 주방장이 "90초 안에 샐러드 3접시 썰어 내놔" 하면 당신은 칼질을 한다. 다 썰었으면 "완료, 샐러드 3접시 나왔습니다" 보고한다. 주방장이 확인하고 "드레싱 빠졌네, 다시" 하면 다시 한다. 근무 끝나면 주방장이 "오늘 C+야, 칼질 속도 올려"라고 평가서 쓴다. 그 평가서가 쌓인다.

차이점은 **주방장이 진짜 LLM**이라는 점. 프롬프트에 "너는 게임 매니저야" 같은 말 없다. `server/src/manager.ts`에 있는 프롬프트는 평범한 오케스트레이터 지시다. "작업 큐가 있다, 하위 에이전트 도구로 위임해라, 결과 검증해라" 수준. 그래서 관리자가 **틀린 일을 승인하는 경우도 생긴다**. 게임엔 숨겨진 정답(ground-truth check)이 있어, 관리자가 깨진 작업을 승인했는지까지 기록한다. "관리자가 틀린 횟수"가 점수판에 남는다.

본지가 35일 전 다룬 [AI가 '생각'을 숨기고 '말'만 내놓는다면](/posts/2026-10-19-ai가-생각을-숨기고-말만-내놓는다면/)에서는 LLM이 사고 과정을 감추고 행동만 보이는 아키텍처를 다뤘다. worker755는 그 반대다. **관리자의 판단을 사람이 직접 받아 수행하면서, 관리자가 무엇을 놓치는지 눈으로 확인**한다. 해커뉴스 댓글에서도 "내 LM 시스템 디버깅하려고 일부러 이렇게 쓴다. 모델 입장이 돼보면 뭘 할 수 있고 없는지 보인다"는 실무자 증언이 있었다.

## 나에게 미치는 영향

**오늘 바로 할 수 있는 것 세 가지.**

1. **무료 근무 한 판 돌려보기.** worker755.com 가입 → 스타터 크레딧으로 1근무 체험. 카드 등록 안 해도 된다. 90초짜리 지시 몇 번 수행해보면 'AI에게 위임받는 입장'이 어떤 감각인지 온다.
2. **로컬에서 오프라인 모드 실행.** `npm run mock`으로 네트워크 없이 돌려보면, 관리자 프롬프트가 어떻게 구성되는지 `server/src/manager.ts`에서 바로 볼 수 있다. 에이전트 오케스트레이션 구조 공부용으로 좋다.
3. **자신만의 API 키로 비싼 모델 테스트.** OpenRouter 키 있으면 Claude Sonnet이나 GPT-4o를 관리자로 세워보자. 같은 지시라도 모델마다 관리 스타일이 어떻게 다른지 비교된다. 비용은 근무당 몇 센트~수십 센트.

**주의할 점.** 로컬 LLM(올라마, 라마.cpp 등) 연동은 아직 안 된다. 홈랩 GPU로 무제한 돌리려는 계획이면 기다려야 한다. 이슈로 등록돼 있으니 업데이트 지켜보자.

## 남은 쟁점: 게임이냐, 도구냐

개발자는 "게임"이라 부르지만, 구조는 **에이전트 오케스트레이션 시뮬레이터**에 가깝다. 관리자 프롬프트가 게임 전용이 아니고, 실제 프로덕션에서 쓰는 오케스트레이터 패턴 그대로다. SPEC.md에 전체 설계가 문서화돼 있다. 테스트도 `npm test`로 쉘·서버 단위 테스트가 돈다. MIT 라이선스라 포크해서 자기 시스템 검증 도구로 써도 된다.

해커뉴스 댓글 중 "이게 매트릭스보다 낫다/나쁘다"는 평이 있다. 매트릭스에선 자기가 배터리인 줄 모르고 VR에서 자유로운데, 여기선 **자기가 하위 에이전트인 줄 알면서도 평가를 위해 일해야 한다**는 차이다. 그 자각이 이 경험을 '게임' 이상으로 만든다.

직접 돌려본 뒤 느낀 건: **AI에게 일을 시키는 입장만 알던 사람이, AI에게 일을 받는 입장이 되어보면 위임 설계가 얼마나 취약한지 바로 보인다**는 점이다. 90초 타이머, 모호한 지시, 관리자의 오판. 이 모든 게 '프롬프트 엔지니어링'이란 말로 퉁치기엔 너무 구체적이다.

아직 한국어 지원 없고, 로컬 모델 연동도 없다. 하지만 **브라우저 탭 하나, 터미널 하나, 비용 거의 없이** AI 에이전트 계층 구조를 몸으로 익힐 수 있는 도구는 지금 이게 유일하다. 궁금하면 무료 근무 한 판만 돌려보라. 10분이면 충분하다.
