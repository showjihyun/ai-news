미국 AI 스타트업 리커시브 인텔리전스(Ricursive Intelligence)가 650억(65B) 파라미터 밀집형 모델 '리플-65B 프리뷰'를 공개했다. 에이전틱 코딩 벤치마크 터미널벤치 2.1에서 80.52점을 받아 미국 오픈웨이트 모델 중 1위에 올랐다. 501B 파라미터의 리플렉션 빔(80.1), 816B의 메타 뮤즈 스파크 오픈(76.4), 975B의 씽킹 머신 잉클링(63.8), 550B의 엔비디아 네모트론 3 울트라(56.4)보다 앞섰다. 파라미터 수로는 8~15배 작은 모델이 이긴 셈이다.

## 개발비 3200만 달러, 이전 SOTA의 10분의 1

리커시브는 순수 연구개발비 3200만 달러(약 450억 원)를 썼다. 사전훈련 래더 개발, 데이터 믹싱, 평가, 디버깅, 합성 데이터 생성, 후훈련 레시피 개발, 최종 히어로 런까지 전 과정 포함이다. 2023년 샘 올트먼이 밝힌 GPT-4 훈련비 1억 달러와 비교하면 **약 3분의 1 수준**이다. 다리오 아모데이가 전망한 프론티어 모델 10억~100억 달러와 견주면 30~300배 저렴하다. 이전 오픈웨이트 SOTA 대비로는 **10분의 1 비용**으로 개발했다.

비결은 무식한 강화학습(RL) 대신 **SFT(지도 미세조정)와 RL 레시피를 반복 개선**한 데 있다. 후훈련 데이터를 사지 않고 자체 합성 파이프라인을 구축했다. 잘린 중요도 샘플링, 점수 중심화, 선형 길이 페널티를 섞은 RL 레시피로 140만 롤아웃 만에 80.5점을 찍었다. 이전 SOTA인 리플렉션 빔보다 롤아웃 수를 **70분의 1로 줄였다**.

## 밀집형 구조가 가져온 의외의 이점

대부분 연구실이 파라미터 효율을 위해 MoE(전문가 혼합) 구조를 택할 때 리커시브는 **밀집형 트랜스포머**를 고집했다. 엔비디아 하드웨어에서 훈련·서빙 인프라 복잡도를 낮추려는 의도였다. 결과적으로 **MFU(모델 FLOPs 활용률) 40%**를 사전훈련과 후훈련 내내 유지했다. 커스텀 커널도, 양자화도 없이 단순 샤딩만으로 달성한 수치다.

아키텍처는 **'얇고 깊은(thin-and-deep)'** 비율이다. d_model(임베딩 차원) 5120에 80개 레이어를 쌓았다. 어텐션 헤드 수를 과도하게 늘리고, SWA(슬라이딩 윈도 어텐션) 비율을 높이되 윈도 크기를 줄여 연산량 증가를 상쇄했다. FFN 활성화 클리핑, 게이티드 어텐션, 글로벌 NoPE, 밸류 잔차 연결도 추가했다. 이 설계 덕에 **데이터센터 GPU 2×B200에서 초당 250토큰** 생성 속도를 낸다. 양자화나 커스텀 커널 없이.

## 100만 컨텍스트, 로컬 실행 가능

사전훈련은 12조 토큰(주로 영어·코드), 8K 시퀀스 길이로 진행했다. 100만 토큰 컨텍스트 길이를 지원한다. 허깅페이스, 투게더 AI, GMI 클라우드, 오픈라우터에서 바로 쓸 수 있다. 파이어웍스도 당일 합류 예정.

**65B 파라미터면 엔비디아 DGX 스파크 같은 컨슈머 하드웨어에서도 돌릴 수 있다.** 로컬 개발을 독려하려고 NVFP4 양자화 체크포인트와 콜랩 노트북도 제공한다. 아파치 2.0 라이선스라 상업 이용도 자유롭다.

## 글로벌 SOTA 주장엔 이견도

해커뉴스 댓글에선 "미국 오픈웨이트 SOTA"라는 수식어에 반론이 나왔다. **무샷 AI의 키미 K3.1 프로**가 글로벌 오픈웨이트 모델 중 더 높은 점수를 냈기 때문이다. "오픈웨이트면 미국·중국 구분이 무슨 의미냐"는 지적도 있었다. 데이터 프라이버시 우려로 **중국 모델을 유럽 서버에서 돌리는 조합**을 선호한다는 댓글도 보였다.

맥 사용자에겐 아쉬운 소식도 있다. **"밀집형 모델이라 맥에서 느릴 것"**이란 지적이 댓글에 한 차례 등장했다. 애플 실리콘의 메모리 대역폭 구조상 밀집형 큰 모델 추론이 불리하다는 뜻이다.

## 쉽게 풀어보면

리커시브 인텔리전스가 코딩 에이전트 특화 모델 **리플-65B 프리뷰**를 내놨습니다. 이 모델은 **파라미터 수 650억 개**로, 자기보다 8~15배 큰 미국 오픈웨이트 모델들을 제치고 에이전틱 코딩 벤치마크 1위를 차지했습니다.

비유하자면 이렇습니다. **경량급 복서가 헤비급 챔피언들을 연달아 KO시킨 격**입니다. 비결은 몸집 키우기(파라미터 늘리기) 대신 **훈련 레시피와 아키텍처를 정교하게 다듬은 것**입니다. 무식하게 강화학습만 돌리는 대신, 지도 미세조정(SFT)과 강화학습(RL) 레시피를 수십 번 반복 개선했습니다. 데이터도 사지 않고 직접 합성해 만들었습니다. 그 결과 **이전 1위 모델보다 70배 적은 연습량**으로 더 높은 점수를 냈습니다.

개발비는 **3200만 달러(약 450억 원)**. GPT-4 훈련비의 **3분의 1**, 프론티어 모델 예산의 **100분의 1 수준**입니다. **돈보다 엔지니어링으로 이긴 사례**입니다.

모델 구조도 특이합니다. 요즘 대세인 MoE(전문가 혼합) 대신 **밀집형 트랜스포머**를 썼습니다. '얇고 깊게' 설계해(임베딩 차원 5120, 레이어 80개) 엔비디아 GPU에서 훈련 효율 40%를 유지했습니다. 커스텀 커널 없이 표준 도구만으로 이뤄낸 성과라 재현성이 높습니다.

**100만 토큰 컨텍스트**를 지원하고, **아파치 2.0 라이선스**로 공개됐습니다. 허깅페이스·투게더 AI·오픈라우터 등에서 바로 내려받아 쓸 수 있습니다. **65B 크기면 엔비디아 DGX 스파크 같은 개인용 워크스테이션에서도 돌아갑니다.** NVFP4 양자화 버전과 콜랩 예제도 제공하니 로컬 테스트 진입장벽이 낮습니다.

단, **맥북에서는 느릴 수 있습니다.** 밀집형 큰 모델은 애플 실리콘의 메모리 대역폭 구조와 궁합이 안 맞기 때문입니다. "글로벌 1위" 주장도 무샷 AI의 키미 K3.1 프로가 더 높은 점수를 받아 논란이 있습니다. 미국 오픈웨이트 한정 1위라는 게 정확한 표현입니다.

## 나에게 미치는 영향

**오늘 바로 해볼 수 있는 것**

- **허깅페이스에서 리플-65B 인스트럭트 모델을 내려받아 테스트**해 보세요. `ricursive/Ripple-65B-Preview` 저장소에 BF16·NVFP4 버전이 있습니다.
- **로컬 실행이 목표라면 NVFP4 양자화 버전 + 콜랩 노트북** 조합으로 시작하세요. DGX 스파크나 RTX 4090 2장(48GB VRAM) 이상이면 BF16도 가능합니다.
- **클라우드에서 바로 써보려면 투게더 AI나 오픈라우터**에서 API 키만 발급하면 됩니다. 별도 서버 구성 불필요.

**주의할 점**

- 맥북 M시리즈에서는 **추론 속도가 기대 이하일 수 있습니다.** 밀집형 65B 모델 특성상 메모리 대역폭 병목이 큽니다. 맥 사용자라면 클라우드 API나 리눅스 머신을 권합니다.
- **에이전틱 코딩 특화** 모델입니다. 일반 대화·창작·번역 용도라면 다른 모델(라마 3.1, 네모트론, 키미 등)과 비교 테스트 후 결정하세요.
- **한국어 성능은 공개되지 않았습니다.** 사전훈련 데이터가 '주로 영어·코드'라 한국어 벤치마크 점수는 미확인입니다. 한국어 코딩 작업 시 프롬프트 엔지니어링이 더 필요할 수 있습니다.

**기존 구독 갈아탈까?**

- **챗GPT 플러스/프로, 클로드 프로** 쓰고 있다면 **당장 갈아탈 필요 없습니다.** 이 모델은 '직접 돌리고 싶은 개발자·연구자' 대상입니다. API 호출 비용만 아끼려는 거라면 클라우드 제공업체 가격표(투게더 AI 등)부터 비교하세요.
- **코딩 에이전트 직접 구축 중이라면** 리플-65B를 베이스 모델로 파인튜닝하거나 RAG 파이프라인에 꽂아 테스트해 볼 가치가 큽니다. 아파치 2.0 라이선스라 상업 임베딩도 자유롭습니다.

## 남은 쟁점

**독립 재현 벤치마크가 없습니다.** 리커시브가 공개한 점수는 자사 평가 파이프라인(터미너스 2 하네스, 128K 시퀀스, 요약 포함) 기준입니다. 해커뉴스 댓글에서도 "재현이 어렵다"는 지적이 나왔습니다. 서드파티 평가(예: 라마인덱스, 오픈컴패스, 로컬LLaMA 커뮤니티 벤치) 결과가 나와야 진짜 실력을 알 수 있습니다.

**장문 컨텍스트 실성능도 미검증입니다.** 100만 토큰 지원한다고 했지만, 실제 100만 토큰 꽉 채워 에이전틱 태스크를 돌렸을 때 품질·속도·비용 데이터는 없습니다. 미드트레이닝·롱컨텍스트 SFT를 거쳤다고만 밝혔습니다.

**한국어·다국어 성능은 알 수 없습니다.** 자료 어디에도 한국어 벤치마크 점수가 없습니다. 국내 실무 투입 전 별도 평가가 필요합니다.

**모델 분석 데스크 관점** — 리플-65B는 '파라미터 수로 승부하지 않고 아키텍처·레시피·인프라 공동 최적화로 이긴 드문 사례'입니다. **지금 써야 할 사람: 로컬에서 코딩 에이전트 돌리고 싶은 개발자, 오픈웨이트 베이스 모델 찾아 파인튜닝하려는 팀.** **기다려도 되는 사람: 챗GPT/클로드 쓰며 불편 없는 일반 사용자, 맥북만 있는 사용자, 한국어 작업 비중 큰 팀.** 독립 벤치마크와 한국어 평가 나올 때까지 관망해도 늦지 않습니다.
