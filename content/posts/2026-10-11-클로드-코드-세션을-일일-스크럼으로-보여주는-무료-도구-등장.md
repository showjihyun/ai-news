## 클로드 코드 세션이 '팀 회의'가 된다

프랑스 개발자 더블 제스트(@double_geste)가 **'에이전트 스탠드업(Agent Standup)'**을 깃허브에 공개했다. 클로드 코드(Claude Code)가 이미 로컬에 남기는 세션 파일을 읽어, 여러 서브 에이전트가 **서로 무엇을 기다리고 어디에서 막혔는지**를 실시간 화면과 음성으로 보여준다.

설치·설정 없이 `npx @double_geste/agent-standup --open` 한 줄이면 30초 만에 실행된다. VS 코드, 커서, 일반 터미널, 데스크톱 앱 어디에서 클로드 코드를 쓰든 그대로 붙는다. **코드는 단 한 바이트도 외부로 나가지 않는다.** (프랑스어 번역이나 농담 기능을 켤 때만 짧은 문장이 본인 클로드 계정으로 간다)

## 왜 '스크럼' 형식을 빌렸나

개발팀에서 매일 15분 서서 하는 '데일리 스크럼'은 **누가 누굴 기다리고, 어디서 막혔는지**를 빨리 맞추려는 회의다. 이 도구는 그 형식을 AI 에이전트들에게 그대로 적용했다. 리드 에이전트가 지시하면 서브 에이전트들이 '화면 공유'하듯 상태를 보고하고, 의존 관계가 그래프로 뜬다.

핵심은 **토큰 비용 0원**이라는 점. 클로드 코드가 이미 쓰는 세션 파일을 읽기만 하니 추가 API 호출이 없다. 목소리(맥에서 더 자연스럽다)와 실시간 갱신까지 로컬에서 돈다.

## 쉽게 풀어보면

**에이전트 스탠드업은 클로드 코드가 이미 내 컴퓨터에 적어둔 '작업 일지'를 읽어서, 여러 AI 비서가 서로 '나 이거 기다려', '나 여기 막혔어'라고 말하는 장면을 실시간으로 보여주는 도구입니다.**

비유하자면 이렇습니다. 클로드 코드는 여러 하청 업체(서브 에이전트)를 두고 공사를 진행하는 현장 소장입니다. 각 하청 업체는 자기 할 일을 하다가 자재가 안 와서 기다리거나, 설계가 꼬여서 막힐 수 있습니다. 소장이 일일이 전화 돌리지 않아도, 현장 사무실 화이트보드에 **'A팀: 철근 대기 중', 'B팀: 도면 수정 기다림'**이라고 실시간으로 적혀 있으면 전체 흐름이 보입니다.

이 도구가 바로 그 화이트보드입니다. **따로 서버를 두지 않고, 내 컴퓨터 안에 있는 로그 파일만 읽어서 그립니다.** 그래서 비용이 없고, 코드가 밖으로 새어 나갈 걱정도 없습니다.

## 한국 개발자가 오늘 바로 써보려면

1. **클로드 코드를 이 컴퓨터에서 한 번이라도 실행한 적 있어야 한다** (세션 파일이 있어야 하므로)
2. 터미널에서 `npx @double_geste/agent-standup --open` 입력
3. 브라우저 창이 뜨며 실시간 스탠드업 화면이 나타난다

맥·윈도우·리눅스 모두 지원한다. VS 코드 확장 마켓에서 'Agent Standup'으로 검색해도 설치된다. (맥은 미서명 앱이라 최초 실행 시 우클릭 → 열기 필요)

## 커뮤니티 반응: '유용하다' vs '보여주기용이다'

해커뉴스 댓글 32개 중 눈에 띄는 두 갈래다.

- **긍정**: "사람 스크럼에서도 의외의 연결고리가 발견된다. 에이전트끼리도 '나 그거 어제 봤는데' 같은 정보 공유가 자동으로 되면 쓸모 있겠다"
- **부정**: "사기당하기 좋은 사람을 홀리려는 쇼다. 봇이 사람 흉내 내는 인터넷이 이미 망가졌는데 이런 것까지 더하냐"

**이 대목이 걸린다.** 개발자 본인이 "이 개발자는 자기 에이전트들에게 대체됐다"는 농담을 README에 적어뒀다. 농담 반 진담 반으로, **'에이전트가 에이전트를 관리하는 모습'을 시각화해 보여주는 것 자체가 마케팅**일 수 있다. 그래도 **로컬 실행·무료·오픈소스**라는 세 조건을 다 채운 도구는 드물다.

## 나에게 미치는 영향

**지금 클로드 코드를 쓰고 있다면** 터미널 한 줄로 바로 확인 가능하다. 별도 가입·결제·설정 없다.

```bash
npx @double_geste/agent-standup --open
```

**클로드 코드를 안 써봤다면** 이 도구부터 쓰지는 못한다. 먼저 클로드 코드(별도 구독 필요할 수 있음·본지 미확인)로 아무 작업이나 한 번 돌려 세션 파일을 만들어야 한다.

**대체할 도구인가?** 아니다. 코드 작성 자체를 돕는 도구가 아니라 **이미 돌아가는 에이전트 워크플로를 '가시화'하는 관찰 도구**다. 멀티 에이전트 파이프라인을 짜는 개발자라면 병목 지점을 눈에 띄게 잡을 수 있다. 혼자 소규모로 쓰는 사람이라면 '볼거리는 좋은데 쓸 일은 드물다'고 느낄 수 있다.

## 남은 쟁점

- **한국어 음성 지원**: README에 한국어 언급이 없다. 프랑스어 번역만 명시돼 있다.
- **다른 에이전트 도구 연동**: 코덱스 CLI, 제미나이 CLI 등은 '로드맵'에만 올라 있다.
- **대규모 세션 성능**: 수천 개 에이전트 동시 실행 시 브라우저 렌더링 부하가 어떨지는 실사용 검증이 필요하다.

공개 직후라 이슈·PR이 얼마나 빨리 붙을지가 이 도구의 생명을 가를 것이다.
