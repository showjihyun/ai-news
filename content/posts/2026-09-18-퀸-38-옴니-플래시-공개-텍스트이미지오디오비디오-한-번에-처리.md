알리바바 클라우드가 퀸 3.8 옴니 플래시(Qwen3.8-Omni-Flash)를 공개했다. 텍스트·이미지·오디오·비디오를 동시에 입력받아 이해·계획·도구 호출·결과 생성까지 한 모델에서 처리한다. 컨텍스트 창은 100만 토큰이다.

## 무엇이 달라졌나

발표문에 따르면 퀸 자체 평가에서 이전 모델인 퀸 3.5 옴니 플러스보다 29개 지표에서 성능이 올랐다. **'네이티브 옴니모달'**이라는 표현을 썼다. 입출력 모달리티를 후처리나 별도 파이프라인 없이 모델 내부에서 통합했다는 뜻이다.

기존 퀸 3.8 플래시 넥스트와는 용도가 다르다. 본지가 23일 전 다룬 [퀸 3.8 플래시 넥스트](/posts/2026-08-27-퀸-38-플래시-넥스트-공개-125b-moe가-6b만-깨워-쓴다/)는 125B 파라미터 MoE 구조로 6B만 활성화해 추론 효율을 노린 텍스트 모델이다. 이번 옴니 플래시는 멀티모달 이해·생성에 초점을 맞춘 별도 라인업으로 보인다.

## 커뮤니티 반응은 냉정하다

해커뉴스 댓글 78개 중 다수는 발표 내용보다 블로그 페이지 자체를 비판했다. "기술적으로 인상적이지 않다", "스크롤이 버벅거리고 콘솔에 경고가 가득하다", "영상은 화려하지만 문단 하나로 충분한 내용을 담고 있다"는 지적이 나왔다.

반면 "제미나이 API는 PDF 파일을 그대로 보낼 수 있어 쓰는데, 구글 API 의존이 장기적으론 두렵다"며 대안 모델을 찾는 목소리도 있었다. GLM 플래시 5.3을 파이프라인에 넣어 테스트 중이라는 개발자도 있었다.

## 가격·공개 시점·한국어 성능은 미공개

가장 중요한 정보 세 가지가 빠져 있다. **API 요금**, **정식 서비스 개시일**, **한국어 벤치마크**다. 발표문 어디에도 없다. 본지가 확인하지 못했습니다.

## 쉽게 풀어보면

퀸 3.8 옴니 플래시는 **눈·귀·글을 한꺼번에 이해하는 모델**이다. PDF 문서를 넣으면서 관련 이미지와 음성 메모를 같이 주고 "이걸 요약해서 프레젠테이션 초안 만들어줘"라고 한 번에 시킬 수 있다. 100만 토큰 컨텍스트는 책 한 권 분량(약 70만 자)을 한 번에 기억한다는 뜻이다.

비유하자면 **전문 비서 한 명이 속기·번역·디자인·코딩을 동시에 하는 상황**이다. 이전에는 텍스트 모델, 이미지 모델, 음성 모델을 따로 돌려야 했다. 이제는 단일 모델이 파이프라인 전체를 맡는다.

다만 이 비유가 성립하려면 세 조건이 충족돼야 한다. 한국어 문서 이해가 자연스러워야 하고, API 응답 속도가 실무에 쓸 만해야 하며, 요금이 기존 다중 모델 조합보다 싸야 한다. 셋 다 아직 확인 안 됐다.

## 나에게 미치는 영향

**당장 쓸 수 있는 건 없다.** 정식 API가 열리지 않았다. 알리바바 클라우드 계정이 있고 콘솔을 쓰는 개발자라면 모델 목록에 뜨는지 주 1회 정도 확인하면 된다.

**일반 사용자라면** 챗GPT·클로드·제미나이에서 이미 파일 업로드·이미지 분석·음성 입력을 지원한다. 퀸 옴니 플래시가 이들을 대체하려면 한국어 품질과 가격 경쟁력이 증명돼야 한다. 지금 갈아탈 이유는 없다.

**지켜볼 포인트 세 가지**만 메모해 두자.
- 요금표에 'qwen-omni-flash' 항목이 뜨는가
- 한국어 긴 문서(50쪽 이상 PDF) 요약 테스트 결과가 커뮤니티에 올라오는가
- 로컬 실행 지원(라마씨피유·올라마 등)이 언제 추가되는가

본지가 20일 전 다룬 [퀸 3.8 플래시 넥스트 라마씨피유 합류](/posts/2026-08-29-퀸-38-플래시-넥스트-라마씨피유-지원으로-일반-pc에서도-실행-가능/)처럼 옴니 플래시도 로컬 실행 지원이 생기면 듀얼 RTX 3060 환경에서도 테스트해 볼 수 있을 것이다. 그때까지는 관망이 정답이다.

## 남은 쟁점

발표문은 '29개 평가 지표 향상'이라고만 썼다. 어떤 벤치마크인지, 베이스라인 모델 크기가 같은지 밝히지 않았다. 옴니 플래시가 어느 크기와 비교했는지 알 수 없다.

또 '도구 호출' 기능이 어디까지 내장됐는지도 모호하다. 함수 호출 스키마를 모델이 스스로 생성해 실행하는지, 아니면 외부 오케스트레이터가 필요한지 문서가 없다. 이 부분은 API 공개 뒤 개발자 검증이 필요하다.
