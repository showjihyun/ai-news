## 앤스로픽이 내놓은 새 모델, 점수는 1등인데 쓸 수 없다

앤스로픽이 **클로드 페이블 5.2**를 발표했다. 인공지능 분석 사이트 'Artificial Analysis'가 측정한 지능 지수에서 65점을 받아 74개 모델 중 1위에 올랐다. 종전 최고 점수를 경신한 셈이다.

하지만 세부 지표를 펴보면 이야기가 달라진다. 입력 토큰 100만 개당 8달러, 출력 100만 개당 40달러다. 중간값의 4배, 4배 수준이다. 작업 하나 처리하는 데 평균 **46.4분**이 걸린다. 비교 대상 모델 중간값 12.7분의 3.6배다. 답변도 길어서 작업당 출력 토큰이 2억 7500만 개, 중간값의 3.8배에 이른다. 이 모든 걸 합치면 작업당 비용이 **26.54달러**다.

공개 API도 없다. 앤스로픽 내부나 일부 파트너만 쓸 수 있다. 벤치마크 1등 모델이 정작 일반 개발자 손에는 닿지 않는다.

## 해커뉴스에서는 "최고 추론 모드로 돌려 점수 부풀렸다" 지적

커뮤니티 반응은 냉소적이다. 해커뉴스 댓글 219개 중 다수가 **'맥스 추론 모드'**로 측정한 점을 문제 삼는다. 실제 서비스에서 쓰는 '하이'나 '미디엄' 모드로 돌리면 점수는 다소 떨어지지만 속도와 비용이 절반 이하로 좋아진다는 것이다.

한 사용자는 "AA(Artificial Analysis)가 기본값을 최고 추론으로 잡아놔서 모든 모델이 비싸고 느리게 나온다"고 적었다. 또 다른 댓글에선 "구독제 챗GPT가 API 환산하면 더 싸다"며 구독 대비 API 단가 비교가 무의미하다는 주장도 나왔다.

앤스로픽 측 설명을 보면 기본 추론 강도는 '미디엄'이다. 그런데 벤치마크는 '맥스'로 돌렸다. 이 차이만으로도 체감 성능과 비용 그래프가 뒤집힌다.

## 쉽게 풀어보면

앤스로픽이 새 모델 클로드 페이블 5.2를 내놨다. **지능 테스트에서 1등**을 했다. 그런데 시험 볼 때 '최고 난이도 추론 모드'로 풀었다. 일반 모드로는 안 돌린 셈이다.

비유하자면 **수능 만점 받은 학생이 시험 시간 3배 쓰고, 연필심 10배 갈아 끼우며, 답안지 4배 두껍게 쓴 꼴**이다. 점수는 최고인데, 현실에서 그대로 쓰기엔 시간·돈·종이가 너무 든다.

게다가 이 학생은 **외부인에게 과외를 안 해준다**. 앤스로픽 내부와 일부 파트너만 쓴다. 일반 개발자나 기업은 API로 불러 쓸 수 없다.

## 나에게 미치는 영향

오늘 당장 챗GPT나 클로드 웹에서 이 모델을 골라 쓸 수는 없다. **공개 API가 없기 때문**이다.

만약 나중에 공개된다 해도, **작업 하나에 26달러·46분**이면 개인 용도로는 부담스럽다. 코드 리뷰 하나, 문서 요약 하나에 3만 원 가까이 나가는 셈이다. 구독형 챗GPT 플러스(월 20달러)나 클로드 프로(월 20달러)가 훨씬 싸다.

**지금 할 수 있는 행동**: 클로드 웹이나 챗GPT에서 '추론 강도' 설정이 있다면 '높음' 대신 '중간'이나 '낮음'으로 돌려보라. 답변 속도가 빨라지고 토큰 비용(구독 내 사용량)도 아낄 수 있다. 벤치마크 점수만 보고 모델을 고르지 말라는 뜻이다.

## 남은 쟁점: 구독제 vs API, 어느 쪽이 진짜 싼가

해커뉴스 논쟁 핵심은 **'구독제로 무제한 쓰기'와 'API로 쓴 만큼 내기' 중 뭐가 이득인가**다. 한 사용자는 "구독료를 API 단가로 환산하면 구독이 훨씬 싸다"고 주장했다. 반면 "실제 업무에서 토큰을 얼마나 쓰느냐에 따라 달라진다"는 반론도 있었다.

앤스로픽은 구독제 '클로드 프로'와 API 요금을 따로 운용한다. 페이블 5.2가 구독제에 들어올지, 들어올 때 추론 강도를 어디로 고정할지 아직 공개되지 않았다. 이 두 가지가 정해지기 전까진 **'1등 모델' 타이틀은 마케팅 용어에 가깝다**.

## 모델 분석 데스크 메모

- **지금 써야 할 사람**: 앤스로픽 파트너사, 내부 연구원, 비용·속도 제약 없는 엔터프라이즈 R&D팀
- **기다려도 되는 사람**: 개인 개발자, 스타트업, 구독제 AI로 충분한 일반 사용자
- **확인할 포인트**: 공개 API 출시 여부, 구독제 편입 시 추론 기본값, 미디엄 모드 실측 비용·속도

벤치마크 1등이 서비스 1등은 아니다. **비용·속도·접근성 세 축이 맞아야 실용 모델**이다. 페이블 5.2는 아직 세 축 중 하나만 맞췄다.
