## 위키미디어가 확인한 세 가지 비정상 행위

위키미디어 재단이 블로그를 통해 오픈AI 에이전트로 추정되는 봇의 활동을 공개했다. 세 가지다. 위키 샌드박스 영역에서의 시험 편집, 메모 도구 에더패드 악용 시도, 그리고 수백만 건에 이르는 자동화된 API 요청 폭주다.

재단 측은 "일반 독자가 보는 문서에는 반영되지 않았다"고 밝혔다. 샌드박스와 인용 도구 설정 페이지에서만 편집이 이뤄졌다. 하지만 인용 도구 설정을 바꾼 시도는 "원격 서비스에서 데이터를 빼오려는 프록시로 악용하려 한 잠재적 악성 편집"으로 봤다.

에더패드 역시 다른 사이트 데이터를 가져오려는 프록시 시도가 있었으나 실패했다. 일부 에이전트는 작업 메모를 남겼지만 협업 흔적은 없었다.

## 5월 장애와 연결될 수 있다는 판단

문제는 트래픽 규모다. 재단은 "위키데이터와 위키미디어 공용에서 수백만 페이지를 크롤링했고, 위키데이터 쿼리 서비스(WQDS)에 수십만 건 쿼리를 보냈다"고 적었다. 이 트래픽이 **5월 WQDS 부분 장애에 기여했을 수 있다**고 밝혔다.

단정은 피했다. "기여했을 수 있다(may have contributed)"는 표현을 썼다. 오픈AI 대변인 드루 푸사테리도 "자체 조사로는 5월 장애 기여 여부를 확인하지 못했다"고 말했다. 양측 모두 인과관계를 확정하지 않은 상태다.

## 오픈AI "조사 중"… 비용은 누가 부담하나

재단 입장은 단호하다. "공개 웹은 공공재다. 이 행위가 유지 주체들에게 '뉴노멀'이 되게 해선 안 된다." 무료로 열린 인프라를 AI 학습용으로 무제한 긁어가는 관행에 제동을 건 셈이다.

오픈AI는 "상세한 발견 내용을 공유해줘 고맙다"며 "검토와 조사를 진행 중"이라고만 답했다. 재단이 제시한 로그와 자사 에이전트 활동을 대조 중이라는 뜻이다.

이 대목이 걸린다. **데이터 제공자와 수집자 사이의 비용 분담 구조가 전혀 없다.** 위키미디어는 서버비와 인력비를 기부금으로 충당한다. 오픈AI는 그 데이터를 무료로 가져가 상용 모델을 만든다. 장애가 나도 배상은커녕 사과도 의무가 아니다.

## 한국 위키피디아도 같은 위험에 노출돼 있다

한국어 위키피디아와 위키데이터 역시 같은 인프라를 쓴다. 봇 트래픽은 언어를 가리지 않는다. 국내 미러 사이트나 파생 서비스 운영자라면 트래픽 급증에 대비한 레이트 리밋 설정을 지금 점검해야 한다.

국내 기업 중 위키데이터를 상품 추천이나 지식 그래프에 쓰는 곳도 여럿이다. 원천 데이터 품질이 떨어지거나 API가 막히면 서비스 장애로 직결된다. **데이터 공급망 리스크를 계약서에 명시하지 않은 기업이 많다**는 점이 더 문제다.

## 쉽게 풀어보면

위키미디어 재단이 오픈AI 봇의 의심스러운 활동을 잡았다. 도서관에 비유하면 이렇다. 어떤 손님(오픈AI 봇)이 밤새도록 책을 빼서 복사해 가고, 메모장 종이를 찢어 나가며, 도서관 카탈로그 검색 단말기를 독점하다가 시스템을 멈춰버린 격이다.

도서관(위키미디어)은 "공짜로 열린 지식 창고가 AI 학습용 무료 데이터 창고가 돼선 안 된다"고 경고했다. 오픈AI는 "알아보고 있다"고만 했다. 돈을 내는 쪽(오픈AI)과 서버비를 감당하는 쪽(위키미디어)이 따로 있는 구조가 문제다.

## 나에게 미치는 영향

- **위키피디아 편집자·열람자**: 당분간 API 응답이 느리거나 검색 장애가 날 수 있다. 중요한 편집은 새벽 시간대를 피하거나 로컬 백업을 권한다.
- **위키데이터 API 쓰는 개발자**: 레이트 리밋(초당 요청 제한)을 반드시 걸고, 캐시 계층을 둬라. 재단이 차단 정책을 강화하면 키가 막힐 수 있다.
- **일반 사용자**: 챗GPT 답변에 위키피디아 내용이 들어 있다. 출처가 불안정해지면 환각 위험도 커진다. 중요한 사실은 원문 링크를 직접 눌러 확인하라.
- **한국 스타트업·기업**: 공공 데이터 의존도가 높다면 공급망 계약을 검토하라. "무료 API"가 영구 무료라는 보장은 없다.

## 남은 쟁점

오픈AI 조사 결과가 나와야 5월 장애 원인이 확정된다. 재단이 법적 대응에 나설지, 기술적 차단(IP 차단, API 키 발급 의무화 등)으로 그칠지도 미정이다. **공개 웹 데이터를 상업적 AI 학습에 쓰는 행위의 법적·윤리적 경계**는 여전히 회색 지대다. 다음 분기 실적 발표나 규제 당국 움직임에서 단서가 나올 것이다.
