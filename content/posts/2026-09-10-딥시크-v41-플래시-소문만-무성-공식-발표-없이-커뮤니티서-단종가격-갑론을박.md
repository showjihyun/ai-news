## 커뮤니티에서 시작된 소문, 공식 창구는 침묵 중

해커뉴스와 레딧 r/LocalLLaMA에서 딥시크 v4.1 플래시 관련 글이 동시에 올라왔습니다. 해커뉴스 게시물은 378점, 댓글 195개를 모으며 개발자 사이에서 화제가 됐습니다. 레딧 글 제목에는 '소프트 리타이어(soft retired)'라는 표현이 쓰였습니다. 제조사가 조용히 단종시킨다는 뜻입니다. **공식 확인 없이 커뮤니티 용어만으로 단종 여부를 판단하기는 이릅니다.**

## v4 플래시 사용자들은 "일꾼이었다" 평가

해커뉴스 댓글 중 v4 플래시를 실무에 써 본 사용자는 "다른 모델이 짠 계획을 구현하는 용도로 썼는데 최상급이었다"고 적었습니다. '일꾼(workhorse)'이라는 표현까지 썼습니다. 화려한 벤치마크보다 안정적인 코드 생성을 뜻합니다. 반면 **"명시적으로 영어로 답하라고 해도 중국어로 대답한다"**는 불만도 동시에 올라왔습니다. 같은 모델을 두고 평가가 갈리는 지점입니다. 한국어 환경에서도 다국어 응답 안정성은 실무 도입 전 꼭 확인해야 할 변수입니다.

## 가격 논쟁: "하루 두 배 요금 vs 절반 요금"

한 댓글은 **"하루 중 일부 시간대에 요금이 두 배인 API를 프로덕션에 쓰는 곳은 없다"**고 지적했습니다. 다른 댓글은 **"그 시간대가 절반 요금이면 아무도 불만 갖지 않을 것"**이라고 맞받았습니다. 이 대화는 딥시크 API가 시간대별 차등 요금제를 운용 중임을 시사합니다. 하지만 구체적 요금표·할인 구간·적용 시간대는 어느 쪽도 제시하지 않았습니다. **"더 싸고 더 낫다"는 제목만 보고 비용 절감을 기대하기엔 정보가 부족합니다.**

## 올라마 비판 글 링크가 왜 여기에?

해커뉴스 스레드에 '올라마 쓰지 마라'는 외부 블로그 링크가 공유됐습니다. 올라마는 로컬에서 LLM을 돌리는 인기 도구입니다. 이 링크가 왜 딥시크 스레드에 떴는지는 불분명합니다. 다만 로컬 실행 환경에서 모델 퀀타이제이션(양자화, 모델 크기를 줄여 연산량을 낮추는 기술) 방식에 따라 성능 차이가 크다는 지적이 개발자 사이에 반복돼 온 맥락으로 보입니다. v4.1 플래시가 로컬 실행용으로도 배포된다면, 올라마 같은 런타임 선택이 체감 성능을 가를 수 있습니다.

## 한국 사용자가 지금 확인할 수 있는 것

딥시크 챗 웹사이트에 접속해 현재 제공 중인 모델 목록을 보면 됩니다. v4 프로가 여전히 기본으로 떠 있다면 v4.1 플래시 전환은 아직입니다. **개발자라면 API 플레이그라운드에서 모델 드롭다운을 매일 한 번 열어 보세요.** 허깅페이스 딥시크 조직 페이지에서 새로운 리포지토리 생성 여부를 주기적으로 확인하는 것도 방법입니다.

- 딥시크 챗(chat.deepseek.com) 모델 선택창 확인
- API 플레이그라운드 모델 드롭다운 매일 체크
- 허깅페이스 딥시크 조직 페이지 신규 리포지토리 모니터링

## 쉽게 풀어보면

**딥시크가 v4.1 플래시라는 새 모델을 내놨다는 이야기가 개발자 커뮤니티에서 돌고 있습니다.** 기존 v4 프로보다 싸면서 성능은 더 좋다는 주장입니다. 하지만 딥시크 공식 채널 어디에도 발표문·가격표·벤치마크 결과가 없습니다. **본지가 확인한 자료에는 공식 발표 여부가 나와 있지 않습니다.** 커뮤니티에서는 v4 플래시를 '믿을 만한 일꾼'이라고 칭찬하는 글과 '중국어만 뱉는다'는 불만이 동시에 보입니다. API 요금도 시간대에 따라 다르다는 정황만 있을 뿐 정확한 숫자는 없습니다. 요약하면: 소문은 크고, 공식 확인은 없고, 쓰던 모델이 사라졌다는 징후도 아직 없습니다.

## 나에게 미치는 영향

**오늘 할 수 있는 행동**: 딥시크 챗(chat.deepseek.com)에 접속해 모델 선택창을 열어 보세요. v4.1 플래시가 보이면 바로 테스트 가능합니다. 안 보인다면 공식 출시 전입니다.  
**개발자라면**: API 플레이그라운드 모델 드롭다운을 매일 한 번 확인하세요. 새 모델명이 뜨면 그때 마이그레이션 테스트를 시작하면 늦지 않습니다.  
**비용 민감한 팀**: 현재 쓰는 v4 프로 호출 로그에 타임스탬프를 찍어 두세요. 나중에 새 요금표와 비교할 기준이 됩니다.

## 남은 쟁점: 공식 발표 전까지는 '검증 대기'가 정답

v4 프로 단종설·v4.1 플래시 성능 우위·가격 인하폭 모두 커뮤니티 발화에만 의존합니다. **이 대목이 걸립니다.** 자료에 나온 건 해커뉴스 점수·댓글 수, 레딧 제목, 댓글 6건의 핵심 문장뿐입니다. 허깅페이스 딥시크 조직 페이지와 공식 트위터(@deepseek_ai)를 북마크해 두세요. 거기서 첫 공식 신호가 옵니다. 그때까지는 기존 모델을 그대로 쓰는 게 가장 안전합니다.
