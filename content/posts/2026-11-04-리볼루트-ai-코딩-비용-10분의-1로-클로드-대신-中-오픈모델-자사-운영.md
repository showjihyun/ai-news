영국 핀테크 리볼루트(Revolut)가 AI 코딩 도구 추론 비용을 약 90% 줄였다. 상용 서비스인 앤스로픽 클로드(Claude)와 구글 제미나이(Gemini)를 걷어내고, 중국 Z.ai가 공개한 GLM 모델을 자사 GPU 클러스터에서 직접 돌리는 방식으로 바꾼 결과다. 데이비드 아비톨(David Abitbol) 리볼루트 운영·인프라 리드는 지난달 뉴욕 'AI 엔지니어 컨퍼런스'에서 이 수치를 공개했다.

## 2천 명 엔지니어, 월 1만 달러 청구서가 문제였다

리볼루트는 2025년 초 제미나이, 2026년 초 클로드 코드(Claude Code)를 시험했다. 엔지니어 1인당 월 1,000~1만 달러가 나왔지만 투자 대비 효과(ROI)는 불분명했다. 아비톨은 "엄격한 예산 한도를 두고 토큰을 배급했다"고 말했다. 토큰이 비싸니 엔지니어들은 아껴 써야 했고, 디버깅이나 지라(Jira) 티켓 처리 같은 반복 업무에는 AI를 쓰지 못했다.

자체 호스팅으로 돌리니 사정이 달라졌다. GLM-5.1 기준 입력·출력 토큰 100만 개당 0.30달러. 오픈AI 코덱스(Codex)나 클로드 코드 대비 10분의 1 수준이다. "토큰이 싸지면 엔지니어들이 시간을 아끼는 일에 AI를 쓰기 시작한다"는 게 아비톨 설명이다. 코딩 속도 60%, 리드 타임(요청부터 배포까지) 70%가 개선됐다. 가장 큰 병목은 코드 생성이 아니라 디버깅과 티켓 처리였다.

## 7540억 파라미터, 엔비디아 B200 56장으로 돌린다

GLM-5.1은 전체 파라미터(모델의 두뇌 용량에 해당하는 수치) 약 7540억 개, 토큰 생성 시 활성화되는 파라미터 400억 개 규모다. 모델 가중치만 380GB GPU 메모리를 차지한다. 사용자당 컨텍스트(대화 기억 폭) 유지에 6~26GB가 더 든다.

리볼루트는 현재 GLM-5.3을 엔비디아 B200 GPU 56장으로 서빙한다. 엔비디아 DGX B200 시스템(8장짜리) 7대 분량이다. 그런데 아비톨은 "GPU를 더 꽂아서 성능을 올린 게 아니다"라고 못 박았다. 실질적 이득은 하이퍼파라미터(학습·추론 설정값) 조정, NVFP4 양자화(숫자 정밀도를 낮춰 메모리·연산 절약), 프리필·디코드 분리 구현, 컨텍스트 길이 튜닝에서 나왔다.

## "긴 컨텍스트는 사기다"… 256K가 실전 최적

모델 스펙상 100만 토큰 컨텍스트 윈도우를 지원하지만, 아비톨은 단언했다. "긴 컨텍스트는 사기(Long context is a scam)다. 256K면 충분하다." 최적화 후 256K 컨텍스트에서 첫 토큰 응답 3초 미만, 초당 200토큰 생성이 나온다. 엔지니어들이 체감하는 '쾌적함'의 임계점이다. 5초를 넘기면 슬랙(업무 메신저)으로 불만이 쏟아진다고 했다.

흥미로운 건 작업 방식 변화다. "생각 토큰 스트림을 쳐다보지 않는다. 엔지니어들이 병렬로 태스크를 던져놓고 끝났을 때 확인한다." 오후 5시 이후 로그인한 엔지니어들은 초당 800토큰까지 뽑아 쓴다. 여유 자원이 생기면 자동으로 처리량이 올라가는 구조다.

## 중국 모델, 프라이버시 우려는 남았다

GLM은 텍스트 전용이다. UI 작업 등 비전(이미지 이해)이 필요하면 모델 라우터가 제미나이나 GPT 루나(Luna)로 넘긴다. "프론티어(최상위) 모델은 예외 케이스에만 쓴다"는 게 아비톨 방침이다.

그는 "오픈소스가 이제 리볼루트 우선순위"라며 "청구서가 고정돼 있어 월말 충격(bill shock)이 없다"고 강조했다. 다만 중국 오픈 가중치 모델을 쓸 때 프라이버시·보안 우려가 있음을 인정했다. 어디까지 검증했는지는 밝히지 않았다.

## 누가 돈을 벌고 누가 잃나

이 사례는 AI 인프라 자금 흐름을 바꾼다.

**이득을 보는 쪽**
- **엔비디아**: 리볼루트 같은 기업이 API 요금 대신 GPU를 산다. B200 56장면 수억 원대 매출이다. 젠슨 황 엔비디아 CEO가 "오픈이든 클로즈드든 내 칩을 쓴다"고 말한 이유다.
- **자체 인프라 운영 역량 있는 대기업**: 토큰 요금제에서 벗어나 고정비로 전환할 수 있다. 리볼루트급이면 전담팀이 가능하다.
- **중국 오픈모델 생태계(Z.ai 등)**: 서구 기업이 자사 모델을 프로덕션에 채택한 레퍼런스가 생겼다.

**손해를 보는 쪽**
- **앤스로픽, 오픈AI 등 모델 API 업체**: 대량 트래픽 고객이 이탈하면 매출 직격탄이다. 앤스로픽은 올 3분기 매출 170억 달러(약 23조 원) 규모로 추산되는데, 컴퓨팅 비용만 1조 달러(약 1400조 원)에 달할 수 있다는 분석도 있다.
- **중소형 SaaS형 AI 코딩 도구**: 자체 호스팅이 쉬워지면 '래퍼(wrapper) 서비스' 가치는 떨어진다.

**한국 기업에 닿는 지점**
국내 주요 핀테크·빅테크도 리볼루트와 비슷한 규모 엔지니어 조직을 가진다. 토큰 요금제 부담은 공통 과제다. 다만 △GPU 확보 난이도 △중국 모델 데이터 주권·보안 심사 △전담 MLOps(머신러닝 운영) 인력 여부가 실질적 진입 장벽이다. 카카오·네이버·토스·쿠팡 등이 이미 자체 LLM 인프라를 갖추고 있어 도입 검토가 빠를 수 있다. 중견 기업은 클라우드 관리형 서비스(AWS 베드록, Azure AI 등)로 중간 지점을 찾을 가능성이 크다.

본지가 앞서 다룬 [AI로 하드웨어 드라이버 직접 만든다… 리눅스 사용자 새 길 열려](/posts/2026-10-16-ai로-하드웨어-드라이버-직접-만든다-리눅스-사용자-새-길-열려/) 사례에서도 오픈모델을 로컬에서 돌려 비용·보안을 잡는 흐름이 확인됐다. 리볼루트는 이를 기업 단위로 확장한 셈이다.

## 쉽게 풀어보면

리볼루트는 2천 명 개발자가 쓰는 AI 코딩 도구 월 청구서가 너무 비싸자, 중국 회사가 무료로 공개한 AI 모델(GLM)을 자사 서버에서 직접 돌리기로 했다. 엔비디아 최신 GPU 56장을 사서 깔았더니, 토큰 100만 개당 0.3달러로 떨어져 기존 클로드·제미나이 쓰던 비용의 10분의 1이 됐다.

핵심은 '토큰 아껴 쓰기'에서 '마음껏 쓰기'로 바뀐 점이다. 비쌀 땐 중요한 코드만 AI에 맡겼는데, 싸지니 버그 잡기, 티켓 정리, 문서 작성까지 다 AI에 돌린다. 개발자 1인당 코딩 시간 60%, 전체 배포 리드타임 70%가 줄었다.

기술적으로는 '긴 문맥(컨텍스트 100만 토큰) 지원'을 광고하지만 실전에서는 25만 토큰이면 충분하더라, 첫 응답 3초 안에 나와야 개발자가 안 짜증내더라, 같은 현장 노하우가 더 중요했다. GPU 더 꽂는 것보다 설정 튜닝(양자화, 프리필·디코드 분리 등)으로 성능을 뽑아냈다.

단, 이 모델은 글만 읽고 쓴다. 화면 설계 같은 건 여전히 구글·오픈AI 모델을 쓴다. 중국 모델이라 데이터 보안 검토는 별도로 해야 한다.

이 변화는 'AI 모델 회사(앤스로픽, 오픈AI)는 고객을 잃고, GPU 회사(엔비디아)는 고객을 얻는다'는 자금 흐름 이동을 보여준다. 한국 대형 IT·핀테크도 똑같은 계산기를 두드리고 있을 것이다.

## 나에게 미치는 영향

- **일반 직장인·학생**: 지금 쓰는 챗GPT·클로드·제미나이 요금제는 당분간 변함없다. 다만 기업이 '자체 AI'로 갈아타면, 나중에 사내 도구로 더 빠르고 저렴한 AI 도움을 받을 수 있다.
- **개발자·기술 직군**: 회사에 "GPU 사서 모델 직접 돌리면 토큰 비용 10분의 1"이라는 리볼루트 사례를 들고 가 보라. 도입 검토가 시작될 수 있다. 단, 보안 심의·GPU 예산·운영 인력은 별도 과제다.
- **자영업·소기업**: 자체 호스팅은 현실적으로 어렵다. 클라우드 관리형 서비스(aws 베드록, 네이버 클로바 스튜디오 등)로 '고정 요금제' 상품이 나오는지 지켜보라.
- **투자 관점**: 엔비디아·국내 GPU 서버·IDC(데이터센터) 관련주 수혜 여부는 각 기업 실적과 CAPEX(설비투자) 계획으로 확인해야 한다. 모델 API 기업 주가에는 하방 압력이 될 수 있다.
