## 마이크로소프트가 내놓은 7개 모델, 누가 쓰는가

마이크로소프트가 이그나이트 2026에서 **MAI 브랜드로 7개 신모델**을 한꺼번에 공개했다. 보안 특화 'MAI Cyber 2 Flash', 코딩용 'MAI Code 2·Code 2 Flash', 이미지 생성 'MAI Image 2.7·2.7 Flash', 실시간 음성 'MAI Realtime 1', 라우팅 모델 'Decision 1.1'이다. 모두 **가격 대비 성능**을 전면에 내세웠다.

공개 자료를 보면 MAI Code 2는 GPT-6.1 Sol 성능의 98%를 40% 가격에, 클로드 오푸스 5.5의 96%를 5% 가격에 제공한다고 한다. MAI Image 2.7은 인공지능 분석 벤치마크 1위, GPT Image 2.6 대비 5분의 1 가격이다. Decision 1.1은 GPT-6.1 Sol보다 50배 빠르고 79배 싸다고 주장한다.

숫자만 보면 압도적이다. 하지만 **해커뉴스 댓글 4개 중 3개가 "가중치(모델의 두뇌 용량에 해당하는 수치 파일)가 닫혀 있으면 안 쓴다"**는 반응이었다. 한 사용자는 "윈도우 폰 때랑 똑같다"고 했고, 다른 이는 "개발자 아닌 임원한테 파는 전략"이라고 짚었다. 마이크로소프트가 아무리 싸고 빠르게 내놔도, **모델 소유권을 넘기지 않는 한 개발자 층은 외면할 수 있다**는 신호다.

## 라이선스 가중치, 열림과 닫힘 사이

이번 발표에서 가장 다른 대목은 **'MAI Licensed Weights'**다. 프런티어급 MAI 모델을 가져가 **고객의 애저 환경에서 직접 돌릴 수 있게** 해준다. 데이터와 파인튜닝(기존 모델을 내 데이터로 추가 학습) 결과도 고객 소유다. AT&T가 5G 네트워크 분석용 커스텀 모델을 만들어 GPT-6.1 Sol 대비 50분의 1 비용으로 돌렸다는 사례도 곁들였다.

이건 **오픈웨이트도, 완전 폐쇄도 아닌 제3의 길**이다. 기업 입장에선 데이터 주권과 규제 준수를 지키면서 최신 모델을 쓸 수 있다. 하지만 해커뉴스 반응처럼 **"내가 가중치 파일을 내 하드디스크에 못 두면 내 모델이 아니다"**라는 개발자 정서와는 여전히 거리가 있다.

## 코딩 모델 두 가지, 용도가 갈린다

MAI Code 2와 Code 2 Flash는 **같은 코딩 모델이지만 타깃이 다르다**.

- **Code 2**: 일상적 엔터프라이즈 코딩 작업용. 프론트엔드 대시보드·시각화 생성에서 GPT-6 Sol 대비 64% 선호도. 깃허브 코파일럿에서 바로 사용 가능.
- **Code 2 Flash**: 대량·반복 작업용. 코드 설명, 부분 수정, 버그 수정, 빠른 이터레이션. GPT-6 루나 대비 65%, 클로드 하이쿠 5.5 대비 20% 가격으로 세 개 벤치마크에서 동급 성능 주장. 마이크로소프트 파운드리 제한적 프리뷰 제공.

**둘 다 "근본적 과학 연구나 초장기 에이전트 작업에는 아직 튜닝되지 않았다"**고 자료에 명시돼 있다. 이 한 줄이 중요하다. 기업 일상 코딩엔 충분할 수 있어도, 연구·탐색용으로는 아직 아니라는 뜻이다.

## 보안·이미지·음성, 각각 다른 계산법

- **MAI Cyber 2 Flash**: 기존 MAI Cyber 1.1 Flash 대비 출력 토큰 가격 86% 인하. MDASH 스캔의 40% 담당, 한번 쓴 고객 90% 재사용. 보안 특화 모델은 **신뢰 축적 데이터가 진입 장벽**이 된다.
- **MAI Image 2.7 플래시**: 이미지 1,000장당 약 10달러. 대량 생성 시나리오용.
- **MAI Realtime 1**: 음성 분당 0.01달러부터 시작하는 실시간 음성 모델. 다이내믹스 365 벤치마크에서 GPT-Realtime 2.1 앞섬.
- **드래곤 코파일럿 트랜스크라이브**: 미국 의사 3분의 1 사용, 월 1,000만 건 처리, 다국어 오류율 절반 감소.

## 결정 모델, 큰 모델을 아끼는 스위치

Decision 1.1은 **작업 난이도에 따라 모델을 자동 라우팅(배분)한다**. 큰 비싼 모델은 꼭 필요할 때만 쓴다. AA 디시전 인덱스에서 제브·구글·오픈AI 앞섰고, 4,000개 고객사가 쓴다. GPT-6.1 Sol 대비 50배 빠르고 79배 싸다는 수치는 **라우팅 오버헤드를 포함한 전체 시스템 비교**로 보인다. 단일 모델 비교가 아니라는 점은 염두에 둬야 한다.

## 쉽게 풀어보면

**마이크로소프트가 기업 고객용 AI 도구 상자를 새로 짰다. 일곱 가지 전용 연장이다.** 코딩용 두 개, 보안용 하나, 이미지용 두 개, 실시간 음성 하나, 그리고 '어떤 연장 쓸지 자동으로 골라주는 스위치' 하나.

핵심은 **'라이선스 가중치'**라는 새 옵션이다. 마이크로소프트가 만든 최신 모델을 **내 회사 클라우드(애저)에 갖다 놓고, 내 데이터로 다듬어서, 내 직원만 쓰게 돌릴 수 있다**. 모델 파일 자체를 내 컴퓨터에 다운로드하는 건 아니지만, 남의 서버에 데이터 보내지 않고 내 환경에서 완결된다.

비유하자면 **고급 식당 레시피를 내 주방에 가져와서, 내 재료로, 내 손님한테만 내는 셰프를 고용한 셈**이다. 레시피 원본은 여전히 식당(마이크로소프트) 소유지만, 내 주방에서 돌아가니 재료 유출 걱정은 덜다.

개발자 커뮤니티에선 "레시피 종이 자체를 내 손에 쥐여줘야 내 것"이라고 반발한다. 맞는 말이지만, **병원·은행·통신사 같은 규제 산업에선 '내 주방에서 돌아간다'는 조건이 법적 요건을 충족하는 유일한 길이기도 하다**. AT&T가 5G 네트워크 분석 모델을 이 방식으로 돌려 비용을 50분의 1로 줄인 사례가 그 증거다.

코딩 모델 두 가지도 용도가 갈린다. **Code 2는 '제대로 된 기능 하나 만들 때', Code 2 Flash는 '자잘한 수정 수백 번 돌릴 때'** 쓴다. 둘 다 "노벨상 받을 연구용은 아니다"라고 마이크로소프트 스스로 선을 그었다. 일상 업무 자동화엔 충분하다는 뜻이다.

**이 대목이 걸린다.** 발표 자료 어디에도 '가중치 파일을 오프라인으로 빼갈 수 있다'는 문구가 없다. 기업용으로는 충분해도, 개발자 손에 쥐어지는 건 아니다.

## 나에게 미치는 영향

**깃허브 코파일럿 쓰는 개발자라면** 오늘부터 MAI Code 2를 모델 선택지에서 고르세요. 프론트엔드 대시보드·차트 짜는 일이 많다면 Code 2 쪽이 체감상 나을 수 있습니다. **대량 리팩토링·문서화·단순 버그 픽스**가 주 업무라면 Code 2 Flash가 더 쌉니다.

**기업 인프라·보안 담당자라면** MAI Cyber 2 Flash 가격 인하(출력 토큰 86%↓)와 MDASH 검증 이력을 확인해 보세요. 기존 MAI Cyber 1.1 Flash 쓰던 팀이라면 **같은 예산으로 더 강한 모델**을 돌릴 수 있습니다.

**데이터 주권 때문에 퍼블릭 API 못 쓰는 조직**이라면 'MAI Licensed Weights'가 유일한 선택지일 수 있습니다. 애저 테넌트 안에 모델이 도니 데이터 유출 리스크가 줄고, 파인튜닝 결과도 자산으로 남습니다. 다만 **모델 파일 자체를 오프라인 환경으로 빼갈 수는 없다**는 제약은 계약 전에 꼭 확인하세요.

**일반 사용자·학생·프리랜서**에게 당장은 영향 없습니다. 이 모델들은 엔터프라이즈 계약·애저 리소스·깃허브 엔터프라이즈 같은 **기업용 계정·인프라가 전제**입니다. 개인용 챗GPT·클로드·제미나이 대안으로 쓰긴 어렵습니다.

## 남은 쟁점

마이크로소프트 발표만으로는 다음이 안 보입니다.

- 실제 지연 시간·컨텍스트 창 크기·동시 요청 한도·장기 계약 조건
- Decision 1.1의 '50배 빠르고 79배 싸다' 비교가 **단일 모델 대 시스템 라우팅 비교**라 실사용에서 그대로 나타날지 미지수
- 라이선스 가중치 모델의 커스터마이징 비용·최소 약정 기간·지원 SLA

해커뉴스 지적대로 **"임원용 발표 자료에 가까운 수치"**일 가능성을 배제할 수 없습니다. 독립 벤치마크 결과가 쌓여야 진짜 가격·성능비가 보입니다.

마이크로소프트가 **개발자 아닌 구매 결정권자(CTO·CISO·CIO)한테 팔고 있다**는 해커뉴스 분석은 설득력 있습니다. 하지만 **그 구매 결정권자가 '개발자 불만'을 얼마나 감수할지**가 이 모델들의 실제 확산을 가를 것입니다.
